# Codex Slash Commands for Skills and Markdown Files

Timestamp: 2026-11-12 14:40 MST

## Previous prompt

what  "slash" command do I use in codex to list all of the md files that Codex can work with?

## Response

If you mean **skills defined in `SKILL.md` files**, use:

```text
/skills
```

That lists available skills. For **ordinary Markdown documents**, there isn’t a dedicated slash command to list them all. Simply ask:

```text
List all .md files in the current workspace.
```

Use `/mention` to find and reference a particular file in your prompt.
[Official OpenAI documentation](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
